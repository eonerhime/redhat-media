- **Roadmap:** [`../roadmap.md`](../roadmap.md), Milestone 1, Phase 16

- **Started:** 2026-10-16
- **Status:** approved by the owner, 2026-10-16

## What and why

The public site is built and gated (Phases 0–15), but `main` still serves the original static `index.html`. This phase replaces it: `develop` is merged into `main`, the production URL serves the new site, and everything that could only be done on production is done there. Today:

- the Neon `production` branch is empty: no schema, no `rhm_*` roles, no content;
- Vercel **Production** has `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME` but no `DATABASE_URL`, `RATE_LIMIT_SALT` or `NEXT_PUBLIC_SITE_URL`, so a production build of the new site would fail `lib/env.ts` (which is the intended fail-closed behaviour);
- CI migrates only `preview`. Nothing migrates `production`, and `pnpm db:seed` refuses it;
- the monitor checks develop's preview and the Neon preview branch. Its schedule and dispatch run only from `main`, so they have never run;
- Dependabot reads its config from `main`, so it has never run;
- the external checks (securityheaders.com, Open Graph, WhatsApp, PageSpeed Insights) could not run behind deployment protection (Phase 14 D11), and the owner's phone checks were moved here (Phase 15, owner, 2026-10-16);
- no restore from point-in-time has ever been tried.

`develop` descends from `main` (merge base `e55b5f7`), so the release PR merges cleanly and removes `index.html`.

One finding shapes the release: **the database must be migrated and seeded before the production build runs.** Pushing to `main` starts the Vercel build and the CI job at the same moment. A build that finishes first prerenders `/portfolio`, the portfolio detail params and the sitemap against an empty database. It would heal within minutes (`cacheLife("minutes")`, Phase 8), but the first visitors and the first crawl would see an unavailable or empty portfolio. Every later schema change has the same race. D3 makes the order explicit: migrate, seed, then deploy.

## Constraints

- **C1 — No new libraries.** Everything uses what `tech-stack.md` already lists.
- **C2 — The site does not change.** No page, component, CSP, header or rendering-mode change. The route table is compared with develop's CI log. The only new public file is the Search Console token (D11).

- **C7 — Owner actions spelled out.** Every dashboard, terminal and phone step is written as numbered clicks and commands, saying what is on the clipboard and where it came from.
