# RedHat Media

Single-page marketing site for RedHat Media (RHM), a registered Nigerian
media company — photography, videography, digital marketing, social
media management, online presence management, and web/app development.

Static HTML/CSS, no build step. Deployed to Vercel.

To update the logo, replace `assets/logo.png` and swap the placeholder
wordmark block in `index.html`'s `<header>` for an `<img>` tag.
